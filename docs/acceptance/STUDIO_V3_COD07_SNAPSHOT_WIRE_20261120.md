# COD-07 封存快照传输压缩试验

在同一 Linux amd64、Node v24.19.0、Chromium 151.0.7922.34、Docker 28.4.0 `vfs` 环境中，基线及独立压缩原型各顺序执行一个两工作区并发轮次。每个工作区含虚构的 128 文件、128 目录及 4 MiB 源码，确认实际运行并附加输出满 64,000 字节后发送 `/cancel`。测量期间协调暂停了其他已知 Chromium 用例。

四项都记录到独立 Docker die、真实容器移除和完整快照验证先于源码对账。每组完成恢复命令且托管资源清零。快照是这四项进入对账前最后完成的操作。附加传输缩小 99.31%，但两组最慢的最终回执几乎相同。exec 后时间包含解压、解析及完整验证，实测区间不能单独归因于解压。
