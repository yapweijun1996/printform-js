并行原型先等附加命令结束，再按不可变容器 ID 核实封存镜像、broker 属主、工作区、封存 PID1、`exited`、PID 0、独立 PID namespace 和无重启策略。证据不足时维持串行或隔离工作区。每个并行样本都记录到附加退出、同一容器的退出检查、两阶段重叠，以及两阶段各自成功后才进行树对账。真实 `CANCELLED` 回执、原树与版本、独立容器删除、恢复命令和清理均通过。检查到 anchor 挂载只读，快照后 anchor 的 Docker stdout/stderr 日志为空。

4 项相关文件的 36 项单元测试通过。控制测试覆盖只读快照先完成时回执仍为 running、其他写入仍被拒绝，删除失败时等待读取收尾并保留旧树与未知结果，关闭时按同一容器 ID 重试删除，以及快照失败时等待删除后才允许 Close 清理。另有 restart 策略不足时维持串行的测试。

单独的实机改写控制也通过。容器改写同长度文件并恢复 mtime 后才触发取消。新字节和摘要一致、版本递增 1、并发写入返回 `WORKSPACE_BUSY`、旧制品返回 `STALE_ARTIFACT`，之后 patch 和构建成功。Close 后旧回执返回 `WORKSPACE_CLOSED`，最终 Docker 托管容器及卷均为零。

本机脚本和脱敏追踪位于 `/workspace/scratch/pf-anchor-overlap-phase/`。串行追踪 SHA-256 为 `0925db7df8527e33f6a40515f441b60cb0981ffe2e1f31c93e40e8d22b5bc0a5`，并行追踪为 `c2691df59c63771ea15e4d3bad4bb245a841aed8b4fedd34b04c9cc47c074ae1`。两阶段各自在并行样本中耗时更长，约 300 毫秒的重叠与最终回执的差异是两个观测量。两个变体的小样本均低于 1 秒，顺序运行的两组不足以估计尾延迟或把差值完全归因于并行。实际重复负载的 p95 仍以原 100 项数据 8,137.53 毫秒为准。COD-07 与独立浏览器 Stop 计时保持开放。 [100 样本数据](STUDIO_V3_G6_LOAD_20261120.md)
