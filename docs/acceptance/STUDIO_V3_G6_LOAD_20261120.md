# Studio v3 G6 本地负载和 Stop 证据

本地 Linux amd64，Node 24.19.0，Docker Engine 28.4.0，Playwright Chromium 151.0.7922.34。宿主对工作区可见 5 个 CPU，执行环境配额为 4 CPU 和 16 GiB。使用当前源码 `da4fc4236364d39ffc0db8feba5d109dd809534b`、执行器源码哈希 `b6a89aa87b2f8ae3f17adc436fed6e47ef22c7862599bc3a76b5c509b69ef23b` 和 sealed Docker 镜像 `sha256:e1e20d5004eb9a5099fee5a1e30c4e5e8168106e39f76927fea8e61f3eddf147`。其他本地浏览器回归在同一个执行环境并行运行。没有扩大工作区、命令、配额、HTTP 期限或隔离设置。

## 口径

- 使用真实 Chromium 导航配对和本机 HTTP 调用，没有模型请求。每批在同一次配对授权下保留允许上限的两个活跃工作区。每个工作区使用 128 文件、128 目录、总计 4 MiB 的固定虚构源码。命令使用 Node 内置 API 输出 64,000 字节 ASCII 后限时空闲。
- 使用 Docker 单独观察真实容器进入 running，再对同一轮的两个工作区并行查询状态并发出 Stop。状态延迟从浏览器请求调度到收到非等待的状态回执。Stop 延迟包括请求到完整 HTTP 回执其间实际的容器停止及源码对账。
- Docker `die` 事件提供容器进程终止时刻。对每个容器按其独立 ID 核对删除结果，检查取消回执和原源码树。每批另执行实际恢复命令，并在完成后按本次工作区 ID 核对容器和卷均移除。
- p95 取最近秩。只在真实 running 状态下采样该状态延迟。脚本的短复验另测有限个已完成的大回执，单独列出，避免合并不同回执类型。

## 源码改动和命令期限补充控制

另用真实 Chromium 配对和同一镜像执行一个小树样本。先实际构建并导出虚构 JSON，然后在运行命令中用 Node 同步写入 `note.txt`，等独立 Docker 日志看到写入标记再发 Stop。并发 patch 返回 `WORKSPACE_BUSY`。Stop 回执为 `CANCELLED`，源码从版本 1 对账至版本 2，实际读回新文本及其摘要，旧构建产物返回 `STALE_ARTIFACT`。接着运行有限空闲命令，显式 1,500 毫秒预算触发预期的 `COMMAND_TIMEOUT`。下一条普通命令退出码为 0，关闭后本次工作区的容器和卷均为零。此单次对照独立于 100 项负载数据。

## 复现

安装 Chromium headless shell，启动本地 Docker，再用当前 checkout 构建 runner。默认 50 轮，每轮两个工作区。每 25 轮重建工作区，避免穿过现有单工作区调用上限。输出路径必须是新文件。只想验证脚本流程可传入最后一个参数 `1`，采样两次。

```sh
npx playwright install chromium --only-shell
docker build --tag printform-coding-runner:local coding-runner
node scripts/studio-v3-coding-load.mjs g6-load-evidence.jsonl
```

原 100 项使用相同的工作区轮转、原始输出限额与状态／Stop 计时口径。首次驱动直接引用本机 Docker 二进制、固定证据路径和镜像标签，采样前观察容器运行，取消后确认实际输出字节数。仓库驱动改为使用 PATH、显式的新文件路径、可选镜像标签及中断清理，并为 Stop 后已有的完成回执 GET 补上 `completedStatusMs` 计时。最终驱动在计时前独立确认完整日志，将最后一个 ASCII 字节换行，输出仍为 64,000 字节。原无换行命令在运行时日志中只公开 49,152 字节，首次启用严格就绪检查时因此超时。最终驱动在计时前确认已输出目标字节，Stop 后再核对完整回执字节数和同一容器的独立终止时间。原逐项记录保持不变，SHA-256 为 `da10dc28e9a2abe93d751389a04077d817e0abb433e8baa2ad1821ecf9a78c36`。先加入额外回执计时的版本独立跑两项通过，完成回执最大读取 11.45 毫秒。加入严格日志就绪检查和换行后的版本也独立跑两项通过，确认每项完整输出并获得终止事件，完成回执最大读取 85.91 毫秒。这两轮均只有 2 个样本。新计时未回填到 100 项原记录。脚本退出码 0 表示样本和清理检查完成，SLO 仍需按上表独立比对。
